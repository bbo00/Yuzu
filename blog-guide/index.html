윈도우 PC에서 클로드 데스크톱 앱과 크롬 확장을 연결하고, 내 블로그 주제·말투·사진 규칙에 맞춰 매일 초안을 받아 아침에 확인만 하는 12단계입니다. 발행 버튼은 내가 누릅니다.

12단계 스킬 4개 프롬프트 5종 자동은 저장까지

이 가이드가 하는 일

  1. 1연결 — 클로드 앱, 크롬 확장, 네이버 로그인 상태
  2. 2세팅 — 블로그 프로젝트, 사진 폴더, 금지 규칙
  3. 3스킬 — 글감·글쓰기·제품·사진 규칙 4개 업로드
  4. 4자동 — 매일 정해진 시간에 임시저장, 아침 5분 확인
자동 발행이 아닙니다. 저장까지만 자동입니다.

🪪

실명·주소·계정·제휴 링크는 스킬 파일이 아니라 내 프로젝트 지식에 둔다.

⚠️

확인한 것만 쓴다

가격·영업시간·검색량은 확인한 날짜와 함께. 확인 못 한 값은 비워 두고 알린다.

PART 1

연결 세팅

STEP 01 – 03 · 약 35분

클로드가 내 PC와 내 크롬, 내 네이버 블로그 화면을 다룰 수 있게 만드는 단계입니다. 여기가 되면 나머지는 대화 몇 줄로 끝납니다.

01
STEP 01약 10분

클로드 데스크톱 앱 설치 (윈도우) · 요금제 확인

내 PC에서 클로드 앱이 열리고, 자동화가 되는 요금제인지 확인합니다.

  1. 크롬에서 claude.com/download 를 엽니다. 데스크톱 항목에서 일반 PC는 Windows, ARM 노트북이면 Windows (arm64) 를 받습니다.
  2. 받은 Claude Setup.exe 를 실행합니다. 관리자 승인 창이 뜨면 허용하세요. 거절하면 Cowork가 빠진 설치가 될 수 있습니다.
  3. 설치가 끝나면 시작 메뉴 → Claude 로 실행하고, 웹에서 쓰던 계정으로 로그인합니다.
  4. 요금제를 확인합니다. 왼쪽 아래 이름 → 설정(Settings) → 계정/요금제 에서 Pro · Max · Ultra 중 하나여야 4단계 자동화가 됩니다.
  5. 왼쪽 사이드바에 Cowork(또는 채팅·Cowork 통합 화면)와 Scheduled 가 보이는지 봅니다. 안 보이면 설정 → 앱 정보 → 업데이트 확인 으로 최신 버전으로 올립니다.
  6. 예약 작업이 PC 절전으로 건너뛰지 않게 설정 → 시스템(또는 이 컴퓨터 → 시스템) → 컴퓨터 절전 모드 방지 를 켭니다.
성공
시작 메뉴에 Claude가 있고, 로그인된 화면 왼쪽에 Cowork · Scheduled(예약됨)가 보이면 끝입니다.
주의

무료 플랜에서는 Claude in Chrome · 예약된 작업 · Cowork를 쓸 수 없습니다. 이 가이드의 자동화는 모두 유료 기능입니다.

요금제와 클로드 사용량은 가이드에 포함된 비용이 아닙니다. 먼저 Pro로 한 달 써 보고 늘릴지 정하는 편이 안전합니다.

TIP
하루 적정량은 Pro 1편 · Max 2~3편입니다. 사진 읽기와 키워드 확인에 사용량이 꽤 들어서, 욕심내면 저녁에 글이 안 나옵니다.
02
STEP 02약 15분

크롬 연결 + 사진 폴더 접근 (윈도우 경로)

클로드가 내 크롬에서 네이버 화면을 읽고 클릭하게 하고, 바탕화면 사진 폴더를 읽게 합니다.

A. 크롬 연결 (Claude in Chrome) — 네이버 글쓰기 화면을 다루려면 이 확장이 필요합니다.

  1. 구글 크롬을 최신으로 올립니다. 주소창에 chrome://settings/help 를 넣으면 버전을 확인할 수 있습니다. 엣지·웨일·모바일은 지원하지 않습니다.
  2. 크롬 웹 스토어에서 Claude in Chrome 을 검색합니다. 게시자(개발자)가 Anthropic / claude.com 인지 확인하고 Chrome에 추가 를 누릅니다.
  3. Claude 계정으로 로그인하고, 요청하는 권한을 허용합니다. 페이지를 읽고 클릭·입력하는 데 필요한 권한입니다.
  4. 주소창 오른쪽 퍼즐 조각 아이콘 → Claude 옆 압정을 눌러 고정합니다. 아이콘을 누르면 오른쪽에 사이드 패널이 열립니다.
  5. 같은 크롬에서 네이버에 직접 로그인해 둡니다. 클로드는 그 로그인 상태를 빌려 씁니다. 비밀번호는 클로드에게 알려주지 않습니다.

B. 사진 폴더 연결 — 두 가지 길 중 하나만 하면 됩니다.

  • 쉬운 길 (권장) — Cowork 대화나 예약 작업을 만들 때 작업 폴더로 C:\Users\사용자명\Desktop\블로그사진 을 고르면 끝입니다. 별도 설치가 없습니다.
  • 고급 길 (MCP 파일시스템) — 폴더를 상시 연결하고 싶을 때만. Node.js LTS를 설치한 뒤 아래 순서로 설정합니다.
  1. PowerShell을 열고 where npx 를 쳐서 경로가 나오는지 확인합니다. 안 나오면 Node.js를 다시 설치합니다.
  2. 클로드 앱에서 설정 → 개발자(Developer) → 구성 편집(Edit Config) 을 누릅니다. 설정 파일이 열리거나 새로 만들어집니다.
  3. 파일 경로는 %APPDATA%\Claude\claude_desktop_config.json 입니다. 아래처럼 넣고, 사용자명만 내 것으로 바꿉니다. 경로의 역슬래시는 두 개씩 써야 합니다.
claude_desktop_config.json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "C:\\Users\\사용자명\\Desktop\\블로그사진"
      ]
    }
  }
}
  1. 저장한 뒤 클로드를 완전히 종료합니다. 창만 닫으면 안 되고, 오른쪽 아래 트레이 아이콘을 우클릭해 종료합니다. 다시 실행하면 연결됩니다.
  2. 대화에서 “블로그사진 폴더에 어떤 파일이 있어?”라고 물어 목록이 나오면 성공입니다.
성공
크롬 사이드 패널의 클로드가 지금 보고 있는 페이지 제목을 말할 수 있고, 사진 폴더의 파일 목록을 읽어 주면 끝입니다.
하지 마세요
사진 폴더만 열어 줍니다. C:\ 전체나 문서·다운로드 폴더 전체를 열면 그 안의 모든 파일을 읽을 수 있게 됩니다.
TIP
사용자 이름이 한글이라 MCP가 자꾸 실패하면 C:\BlogPhotos 처럼 영문 경로에 폴더를 만들고 그 경로로 연결하세요. 폴더를 바탕화면에 두고 싶으면 바로가기로 쓰면 됩니다.
03
STEP 03약 10분

네이버 블로그 첫 임시저장 테스트 (손으로)

임시저장이 어디에 쌓이고 어떻게 불러오는지 내 손으로 먼저 확인합니다. 나중에 클로드가 저장한 글을 찾을 위치입니다.

  1. 크롬에서 blog.naver.com → 내 블로그 → 글쓰기 를 엽니다. 주소로는 blog.naver.com/GoBlogWrite.naver 입니다.
  2. 제목에 임시저장 테스트, 본문에 두 줄, 사진 한 장을 넣습니다.
  3. 오른쪽 위 저장 버튼(발행 버튼 왼쪽)을 누릅니다. 버튼 옆 숫자가 지금까지 쌓인 임시저장 개수입니다.
  4. 그 숫자를 눌러 목록을 열고, 내 글 제목을 눌러 다시 불러와 봅니다.
  5. 테스트 글은 목록에서 X 로 지웁니다. 지금 쓰고 있는 글은 지워지지 않습니다.
  6. 블로그 관리 → 카테고리 관리 에서 글 종류를 미리 만들어 둡니다. 여행 · 맛집 · 제품 정도면 충분합니다.
성공
저장 옆 숫자가 1 늘고, 목록에 내 제목이 보이며, 눌러서 불러와지면 끝입니다.
주의

임시저장은 영구 보관함이 아닙니다. 목록에 300개까지만 보이고, 에디터가 개편되면 오래된 초안이 사라질 수 있습니다.

그래서 매일 쌓아 두기만 하지 말고, 아침에 확인해 발행하거나 지우는 습관이 필요합니다.

PART 2

내 블로그 세팅

STEP 04 – 05 · 약 35분

클로드에게 내 블로그가 무엇을 다루고, 무엇을 쓰면 안 되는지 알려주는 단계입니다. 여기를 대충 하면 매번 남의 블로그 같은 글이 나옵니다.

04
STEP 04약 20분

클로드 프로젝트 만들기 — 주제 · 카테고리 · 금지 규칙

블로그 작업 전용 방을 만듭니다. 대화가 섞이지 않고, 규칙을 매번 다시 설명하지 않아도 됩니다.

  1. 앱 왼쪽 사이드바에서 Projects → 새 프로젝트 를 누르고 이름을 내 블로그 작업실 로 정합니다.
  2. 프로젝트 지침(Instructions)에 아래 글을 붙여넣고, 대괄호 안만 내 것으로 바꿉니다.
  3. 프로젝트 파일(지식)에 세 가지를 올립니다. 블로그 기본 정보, 카테고리와 금지 규칙, 내가 쓴 기준 글 1편.
  4. 앞으로 블로그 작업은 이 프로젝트 안에서만 합니다. 다른 대화에서 하면 규칙을 잊습니다.
프로젝트 지침대괄호만 바꿔서 붙여넣기
너는 내 네이버 블로그 글을 대신 쓰는 도우미다.
- 블로그 주제: [여행 / 맛집 / 제품 리뷰]
- 카테고리: [국내여행, 해외여행, 맛집, 제품리뷰]
- 말투: [존댓말, 담백하게, 감탄사 적게]
- 분량: [1800~2500자], 사진 [6~10장]
- 사진 폴더: [C:\Users\내이름\Desktop\블로그사진]
- 절대 하지 말 것: 발행 버튼 누르기, 로그인·결제, 원본 사진 수정·삭제, 확인 안 된 가격·수치 쓰기, 실명·주소·계좌·전화번호 쓰기, 얼굴·번호판 안 가린 사진 넣기
- 글은 항상 결론부터. 첫 세 줄 안에 답이 있어야 한다.
- 마크다운 기호(#, **, -)는 쓰지 않는다. 네이버 에디터에 글자로 보인다.
- 작업이 끝나면 제목, 카테고리, 사진 수, 임시저장 확인 여부를 한 줄씩 보고한다.
성공
프로젝트가 생기고, 그 안에서 “내 블로그 규칙 알려줘”라고 물으면 방금 넣은 규칙을 그대로 말합니다.
하지 마세요
실명·주소·계좌·아이 얼굴이 담긴 파일은 올리지 않습니다. 프로젝트 지식은 내 계정에 저장되고, 스킬과 달리 대화마다 참고됩니다.
05
STEP 05약 15분

윈도우 사진 폴더 + 얼굴 블러 · 원본 보호 규칙

사진이 쌓일 곳을 정하고, 원본을 잃지 않으면서 얼굴을 가리는 규칙을 정합니다.

  1. 바탕화면에서 우클릭 → 새로 만들기 → 폴더 → 이름 블로그사진. 경로는 C:\Users\사용자명\Desktop\블로그사진 이 됩니다.
  2. 그 안에 다섯 폴더를 만듭니다: 01_여행 · 02_맛집 · 03_제품 · 90_가림 · 99_원본보관.
  3. 파일명은 20261128_애월카페_01.jpg 처럼 날짜_장소_번호로 맞춥니다. 나중에 클로드가 사진을 고를 때 헷갈리지 않습니다.
  4. 원본은 덮어쓰지 않습니다. 가림 처리는 90_가림 폴더에 새 파일로 저장하고, 원본 폴더는 읽기만 합니다.
  5. 아래 목록이 사진에 보이면 반드시 가린 사본을 만들어 그 사본을 글에 넣습니다.
    • 내 얼굴·가족·아이 얼굴 (눈·코·입 전체, 턱선까지)
    • 지나가는 사람, 다른 손님 얼굴
    • 차량 번호판, 문패·동호수, 택배 송장
    • 예약번호, 티켓 바코드, 좌석번호, 명함·전화번호
    • 병원명·진료과가 함께 보이는 화면
  6. 이 규칙을 프로젝트 지식에 사진규칙.md 로 저장합니다. 클로드에게 “사진 폴더 규칙 기억해”라고 말한 뒤 저장해도 됩니다.
성공
폴더 다섯 개가 보이고, 사진 3장을 01_여행에 넣어 두면 클로드가 파일명까지 읽어 줍니다.
TIP
윈도우 기본 사진 앱에는 블러가 없습니다. 휴대폰 모자이크 앱이나 무료 편집 도구로 가린 뒤 90_가림에 넣는 게 가장 빠릅니다. 클로드에게 파이썬으로 처리를 맡겨도 되지만, 결과 사진은 눈으로 직접 확인하세요.

SKILL.md 받기 업로드용 ZIP
왜 두 가지
SKILL.md 는 내용을 읽고 고칠 때, 업로드용 ZIP 은 클로드 앱에 바로 올릴 때 씁니다. 앱은 폴더째 묶은 ZIP만 스킬로 받습니다.
성공
다운로드 폴더에 md 4개와 zip 4개가 있고, 미리보기로 내용이 읽히면 끝입니다.
주의
스킬에는 실명·주소·계정·제휴 링크가 없습니다. 내 정보가 필요한 부분은 프로젝트 지식에 따로 두세요. 스킬은 나중에 공유하거나 복제될 수 있는 파일입니다.

STEP 07약 15분

스킬 올리고 켜기 · 한 번 시험

ZIP 4개를 클로드에 올리고, 실제로 불려 오는지 확인합니다.

  1. 설정 → 기능(Capabilities) 에서 코드 실행 및 파일 생성(새 화면에서는 파일 만들기 및 편집)을 켭니다. 스킬이 이 기능을 씁니다.
  2. Customize(사용자 정의) → 스킬 로 갑니다. 주소는 claude.ai/customize/skills 입니다.
  3. 오른쪽 위 + → 스킬 업로드 → 받은 ZIP 4개를 차례로 올립니다.
  4. 목록에 4개가 생기면 각각 스위치를 켭니다.
  5. ZIP 없이도 됩니다. 프로젝트 지식에 md 파일을 그대로 올리면 참고 문서로 작동합니다. 다만 자동으로 불려 오는 힘은 스킬 쪽이 낫습니다.
  6. 시험해 봅니다: “01-keyword-topic 스킬로 내 블로그 글감 5개 뽑아줘. 사진 폴더에 있는 것만.”
업로드가 안 될 때확인할 것
ZIP 안에 폴더가 또 있음ZIP을 열었을 때 맨 위에 01-keyword-topic/ 폴더 하나만 있어야 합니다. 안에 SKILL.md가 들어 있는 구조입니다.
폴더명과 이름이 다름폴더 이름과 frontmatter의 name 이 같아야 합니다.
파일명 대소문자앱 안내는 skill.md, 문서에 따라 SKILL.md 입니다. 둘 다 되게 하려면 그대로 둔 채, 안 되면 하나 더 넣어 보세요.
frontmatter 항목앱은 name · description 만 받습니다. 다른 항목이 있으면 실패합니다. 우리 파일은 두 개만 있습니다.
성공
글감 후보가 표로 나오고, 확인하지 못한 검색량은 “미확인”이라고 표시됩니다. 그게 정상 동작입니다.

STEP 08약 20분

첫 임시저장 자동 테스트

클로드가 크롬에서 네이버 글쓰기 화면을 열고, 제목·본문·사진을 넣고 저장까지 하는지 확인합니다.

  1. 크롬에서 네이버에 로그인된 상태인지 확인합니다. 로그아웃됐다면 직접 로그인합니다.
  2. 클로드 데스크톱 앱에서 Cowork(또는 채팅) 새 대화를 열고, 작업 폴더로 블로그사진 을 고릅니다.
  3. 아래 프롬프트 ①을 복사해 대괄호만 내 것으로 바꾸고 붙여넣습니다.
  4. 5~10분 기다립니다. 클로드가 새 탭을 열고 글쓰기 화면에서 제목·본문·사진을 넣고 저장을 누릅니다.
  5. 직접 확인합니다. 네이버 글쓰기 → 저장 옆 숫자 → 목록 에 새 제목이 있는지 봅니다.
  6. 발행은 하지 않습니다. 확인만 하고, 잘못된 부분은 프롬프트 ⑤로 한 줄 지시합니다.
프롬프트 ①첫 글 임시저장 테스트
내 블로그에 올릴 테스트 글 하나를 임시저장까지만 해줘. 발행은 절대 하지 마.

1. 사진 폴더: [C:\Users\내이름\Desktop\블로그사진\01_여행]
2. 주제: [제주 애월 카페 3곳]
3. 카테고리: [국내여행]
4. 사진은 6장, 얼굴이 나오면 턱선까지 가리고 새 파일로 저장해줘.
5. 네이버 블로그 글쓰기 화면에서 제목과 본문을 넣고, 사진을 순서대로 넣고, 태그 [제주카페, 애월카페, 제주여행]을 넣은 뒤 오른쪽 위 저장을 눌러서 임시저장해줘.
6. 끝나면 저장 옆 숫자를 눌러 목록에 제목이 보이는지 확인하고 결과를 알려줘. 발행 버튼은 누르지 마.
승인 모드
처음에는 클로드가 클릭할 때마다 물어봅니다. 그대로 두고 하나씩 승인하면서 동작을 보세요. 익숙해지면 예약 작업에만 자동 승인을 씁니다.
즉시 중지
클로드가 발행 버튼으로 가려 하면 바로 멈추게 하세요. 프롬프트에 적어 두어도 화면 구조에 따라 헷갈릴 수 있습니다. 그때는 “발행하지 말고 저장만”이라고 한 번 더 말합니다.
성공
임시저장 목록에 새 글이 있고, 사진이 들어가 있고, 발행되지 않았으면 끝입니다. 이 한 번이 되면 나머지는 반복입니다.

STEP 09약 25분

기준 글 1편으로 말투·분량·사진 배치 맞추기

AI 티를 줄이는 가장 빠른 방법은 설명이 아니라 내가 쓴 글 한 편을 보여주는 것입니다.

  1. 내가 직접 쓴 글 중 마음에 드는 1편을 고릅니다. 1,500자 이상, 사진이 들어간 글이 좋습니다.
  2. 본문을 복사해 메모장에 붙이고 기준글.md 로 저장한 뒤 프로젝트 지식에 올립니다.
  3. 프롬프트 ②로 분석을 맡깁니다.
  4. 나온 문체 카드를 프로젝트 지침 맨 아래에 붙여넣습니다.
  5. 다음 글부터 카드 규칙을 따르는지 봅니다. 어긋나면 프롬프트 ⑤로 한 줄씩 고칩니다.
프롬프트 ②내 말투·기준 글 학습
프로젝트 지식에 올린 기준 글 [파일명]을 읽고 내 문체를 정리해줘.

1. 문장 길이, 문단당 문장 수, 소제목 개수와 말투
2. 사진 개수와 사진이 들어가는 위치
3. 내가 자주 쓰는 표현과 절대 쓰지 않는 표현
4. 도입 방식과 마무리 방식
5. 이 글의 분량과 태그 개수

정리한 내용을 300자 안의 "내 문체 카드"로 요약하고, 프로젝트 지침에 붙여넣을 수 있게 표로도 보여줘. 확인하지 못한 내용은 추측하지 말고 비워 둬.
성공
같은 주제로 두 번 써 봤을 때 첫 문단 길이와 사진 수가 비슷하게 나옵니다. 그게 맞춰졌다는 신호입니다.
TIP
5편쯤 쓰면 카드 없이도 비슷하게 나옵니다. 그때는 기준 글 2~3편만 지식에 남기고 카드는 지워도 됩니다. 지침이 길면 클로드가 앞부분을 놓칩니다.

STEP 10약 20분

제휴 링크 넣기 — 트립닷컴 · 아고다 · 쿠팡 · 브랜드커넥트

내 링크를 정리해 두고, 글에 자연스럽게 넣는 규칙을 정합니다. 고지 문구와 위치가 핵심입니다.

  1. 가입합니다. 쿠팡파트너스(partners.coupang.com) · 트립닷컴 파트너스(kr.trip.com/partners) · 아고다 파트너스(partners.agoda.com) · 네이버 브랜드커넥트(brandconnect.naver.com → 쇼핑 커넥트·여행 커넥트).
  2. 상품 페이지에서 내 링크를 만들어 복사합니다. 짧은 링크가 있으면 그쪽을 씁니다.
  3. 프로젝트 지식에 제휴링크.md 를 만들어 정리합니다. 형식: 브랜드 / 상품명 / 링크 / 만든 날짜.
  4. 프롬프트 ③으로 글에 넣습니다. 위치는 결론 아래 1개, 본문 중간 1개, 맨 끝 1개 — 3개를 넘기지 않습니다.
  5. 글 맨 위에 고지 문구를 넣습니다. 아래 표의 문구를 그대로 씁니다.
프로그램넣는 문구위치
네이버 쇼핑 커넥트이 포스팅은 네이버 쇼핑 커넥트 활동의 일환으로, 판매 발생 시 수수료를 제공받습니다.본문 최상단
트립닷컴본 포스팅은 트립닷컴 제휴 마케팅의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.글 맨 위
아고다 · 쿠팡각 프로그램이 가입 후 안내하는 문구를 그대로 사용글 맨 위
브랜드 협찬이 글은 업체로부터 제품을 제공받아 작성했습니다. 대가를 받았습니다.글 맨 위
프롬프트 ③제휴 링크 삽입
이번 글에 제휴 링크를 넣어줘.

- 링크는 프로젝트 지식의 제휴링크 파일에서만 가져와. 없는 링크를 만들지 마.
- 넣는 위치: 결론 문단 바로 아래 1개, 본문 중간 1개, 글 맨 끝 1개. 그 이상 넣지 마.
- 링크 앞에는 무엇인지 한 줄로 써줘. 예: [숙소 최저가 보기]
- 글 맨 위에 아래 고지 문구를 그대로 넣어줘.
이 글은 제휴 링크를 포함하고 있으며, 구매나 예약 시 일정 수수료를 받을 수 있습니다.
- 확인하지 못한 가격은 쓰지 말고, 가격을 쓰면 확인한 날짜를 함께 적어줘.
- 링크를 넣은 뒤 실제로 열리는지 확인하고 결과를 알려줘.
주의

쇼핑 커넥트 링크를 넣은 글에는 #내돈내산 기능을 쓸 수 없습니다. 대가성 문구를 이미지 안이나 태그 사이에 숨겨도 안 됩니다.

링크를 넣었다고 불이익은 없지만, 글 내용과 상관없는 링크를 많이 넣으면 어뷰징으로 볼 수 있습니다.

수익
제휴 수익은 보장되지 않습니다. 클릭이 없으면 0원입니다. 하루 1편씩 3개월은 쌓아야 숫자가 보입니다.
성공
글 맨 위에 고지가 있고, 링크가 3개 이하이며, 눌렀을 때 실제 페이지가 열리면 끝입니다.

STEP 11약 15분

매일 정해진 시간에 자동 임시저장 걸기

클로드의 예약된 작업으로 매일 아침 초안이 쌓이게 합니다. 실행 조건을 정확히 맞추는 게 중요합니다.

  1. 앱 왼쪽 사이드바 Scheduled(예약됨) → New task → Create with Claude 또는 Set up manually.
  2. 이름을 blog-draft-daily 로, 지침에 프롬프트 ④를 붙여넣습니다.
  3. 빈도는 매일 07:30. 주말은 쉬려면 Weekdays 를 고릅니다.
  4. 작업 폴더로 블로그사진 을 고릅니다. 폴더를 고르면 이 컴퓨터 필요가 켜집니다. 안 켜지면 직접 켭니다.
  5. 승인 모드는 자동으로 둡니다. 매번 승인을 기다리면 아침에 멈춰 있습니다.
  6. 저장한 뒤 Run now 로 한 번 시험합니다. History에 실행이 남는지 봅니다.
프롬프트 ④매일 자동 임시저장
매일 [오전 7시 30분]에 내 블로그 임시저장 글을 하나 만들어줘.

1. 사진 폴더 [C:\Users\내이름\Desktop\블로그사진]에서 아직 안 쓴 사진을 골라.
2. 01-keyword-topic 스킬로 키워드 후보를 3개 뽑고, 그중 경쟁이 가장 약한 하나를 골라.
3. 02-travel-food-post 또는 03-product-affiliate-post 스킬로 본문을 쓰고, 04-photo-format-draft 스킬 규칙대로 사진과 서식을 맞춰.
4. 네이버 블로그 글쓰기에서 임시저장까지만 하고, 발행은 절대 하지 마.
5. 끝나면 제목, 고른 키워드, 사진 수, 임시저장 확인 결과를 한 줄로 알려줘.
6. 오늘 사진이 부족하거나 확인이 안 되면 억지로 쓰지 말고 그 이유만 알려줘.

그래서 이 컴퓨터 필요를 켜야 내 PC에서, 내 크롬으로 저장합니다.

STEP 12매일 5분

아침 5분 확인 후 직접 발행

클로드가 남긴 초안을 확인하고, 내 손으로 발행합니다. 이 5분이 계정을 지킵니다.

  1. 알림을 확인하거나 Scheduled → History 에서 오늘 실행을 엽니다.
  2. 네이버 글쓰기 → 저장 옆 숫자 → 새 글 을 엽니다.
  3. 아래 체크리스트를 위에서부터 봅니다. 하나라도 걸리면 고치고, 반복되는 지적은 프롬프트 ⑤로 한 줄 보냅니다.
  4. 공개 범위·카테고리·예약 발행을 내가 정하고 발행 을 누릅니다.
  5. 발행한 글 주소를 복사해 기록해 둡니다. 나중에 성과를 볼 때 필요합니다.
오늘 확인 0 / 8
프롬프트 ⑤“앞으로는 ~” 한 줄 수정
앞으로는 [첫 문단은 세 줄로 짧게, 결론은 두 문장으로] 써줘. 이 규칙을 프로젝트 지침에 저장하고 다음 글부터 적용해줘.
성공
아침 5분, 고칠 곳 두세 개, 발행 버튼 한 번. 이 리듬이 3주 이어지면 블로그가 살아납니다.
