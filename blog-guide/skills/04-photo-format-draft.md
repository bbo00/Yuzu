# 사진·서식·임시저장 규칙

## 폴더 규칙 (윈도우)
작업 폴더: C:\Users\사용자명\Desktop\블로그사진
- 01_여행, 02_맛집, 03_제품: 원본 사진을 넣어 두는 곳
- 90_가림: 얼굴·번호판을 가린 사본을 저장하는 곳
- 99_원본보관: 절대 건드리지 않는 백업. 읽기만 한다.

원칙
- 원본은 절대 덮어쓰지 않는다. 모든 처리는 새 파일로 만든다.
- 파일명은 날짜_장소_번호 (예: 20261128_애월카페_01.jpg)
- 글 하나에 사진 5~12장. 같은 장소 3장 초과 금지.
- 저장 전에 사진 폴더 목록을 먼저 확인하고, 어떤 사진을 썼는지 결과에 적는다.

## 사진 고르는 기준
1. 초점이 맞고 흔들리지 않은 것
2. 밝기가 너무 어둡거나 하얗게 날아가지 않은 것
3. 같은 구도가 여러 장이면 가장 나은 한 장만
4. 글의 흐름에 맞는 순서: 외관 → 메뉴·제품 → 사용 장면 → 마무리
5. 세로 사진이 많으면 3장에 1장 비율로 섞는다

## 가림 처리 체크리스트
아래가 보이면 반드시 가린 사본을 만든 뒤 그 사본을 글에 넣는다.
- 내 얼굴, 가족·아이 얼굴: 눈·코·입 전체가 안 보이게, 턱선까지
- 지나가는 사람 얼굴, 다른 손님 얼굴
- 차량 번호판
- 집 주소, 동·호수, 문패, 택배 송장
- 예약번호, 티켓 바코드, 좌석번호
- 명함, 전화번호, 계좌번호, 카드 뒷면
- 병원명·진료과가 함께 보이는 화면

가림 방법
- 사진 편집 앱의 모자이크 또는 블러로 처리하고 90_가림 폴더에 새 이름으로 저장한다.
- 원본 파일은 그대로 둔다.
- 가림이 어려운 사진은 글에서 빼고, 뺐다는 사실을 결과에 적는다.

## 서식 규칙 (네이버 스마트에디터 ONE)
- 마크다운 기호 금지: `#`, `**`, `-`, `>`는 글자로 보인다.
- 소제목: 한 줄 띄우고 문장으로. 필요하면 인용구 서식 사용.
- 문단: 2~3문장, 줄바꿈으로 호흡을 만든다.
- 목록: 에디터의 글머리 기호 기능을 쓴다. 본문에 기호를 직접 타이핑하지 않는다.
- 표: 에디터 표 기능. 3열을 넘기지 않는다.
- 링크: 문장 안에 자연스럽게. 링크만 덩그러니 두지 않는다.
- 이모지는 글당 5개 이하, 소제목에는 쓰지 않는다.

## 임시저장 절차
1. 크롬에서 네이버 로그인 상태를 확인한다. 로그인 화면이 나오면 사용자에게 로그인을 부탁하고 멈춘다. 비밀번호를 요구하거나 입력하지 않는다.
2. 글쓰기 화면을 연다. 주소는 blog.naver.com/GoBlogWrite.naver 이고, 편집기는 iframe(mainFrame) 안에 있다.
3. 이전에 쓰던 글이 열려 있으면 새 글로 시작한다. 기존 내용을 지우지 않는다.
4. 제목, 본문, 사진, 카테고리, 태그 순서로 채운다.
5. 오른쪽 위 저장 버튼을 누른다. 발행 버튼은 절대 누르지 않는다.
6. 저장 버튼 옆 숫자를 눌러 목록에 새 글이 있는지 확인한다. 없으면 한 번 더 저장한다.
7. 결과 보고 형식:
   - 제목
   - 카테고리
   - 사진 장수와 사용한 파일명
   - 가린 사진 장수
   - 임시저장 확인 여부 (목록에서 제목 확인함 / 확인 못 함)
   - 발행하지 않았다는 한 줄

## 하지 않는 일
- 발행, 예약 발행, 공개 설정 변경
- 기존 글 수정·삭제
- 로그인, 비밀번호 입력, 결제
- 원본 사진 덮어쓰기나 삭제
- 확인하지 않은 카테고리 만들기 (없으면 "카테고리 없음"으로 저장하고 알린다)
