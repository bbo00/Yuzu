# 제품·제휴 리뷰 글쓰기

## 기본값
- 분량: 1,500~2,200자, 사진 5~10장
- 형식: 스펙 요약 → 장단점 표 → 누구에게 맞는지 → 실사용 후기 → 가격과 링크 → 고지
- 말투: 담백한 존댓말. 광고 문구("완벽해요", "인생템") 금지.
- 마크다운 기호 금지. 네이버 에디터에 `**`, `#`를 쓰지 않는다.

## 구성
1. 제목: 제품명 + 사용 조건 + 결론 한 조각
   예) 19인치 캐리어 기내 반입, 3박 4일은 이걸로 충분했습니다
2. 첫 3줄: 무엇을 얼마나 써 봤는지 먼저 밝힌다. (예: 3주 동안 주 4회 사용)
3. 결론 두 문장: 사도 되는 경우 / 굳이 필요 없는 경우
4. 스펙 요약 표: 무게 / 크기 / 배터리 또는 용량 / 소재 / 가격대 / 보증
5. 장단점 표

| 항목 | 좋았던 점 | 아쉬운 점 |
|---|---|---|
| 무게 |  |  |
| 사용감 |  |  |
| 소음·마감 |  |  |
| 가격 |  |  |

6. 누구에게 맞는지: 3줄. 맞지 않는 사람도 1줄 적는다.
7. 실사용 후기: 상황별 2~3개. 사진 자리 표시.
8. 가격과 링크: 확인한 날짜와 판매처를 적는다.
9. 고지.

## 최저가 확인 규칙
- 가격은 확인한 날짜를 반드시 붙인다. 예) 2026년 11월 28일 확인, 쿠팡 39,900원
- 확인하지 않은 가격, 변동 가능성이 큰 가격은 쓰지 않는다.
- "최저가"라고 쓸 때는 비교한 판매처와 날짜를 같은 문장에 쓴다. 비교하지 않았으면 "판매처별로 다르니 확인"으로 쓴다.
- 정가와 할인가를 섞어 쓰지 않는다. 어느 쪽인지 밝힌다.

## 제휴 링크 넣는 자리
- 결론 문단 바로 아래 1개
- 본문 중간 1개 (실사용 후기 끝)
- 글 맨 끝 1개
- 한 글에 3개를 넘기지 않는다. 같은 링크를 두 번 넣지 않는다.
- 링크 앞에는 무엇인지 한 줄로 쓴다. 예) "숙소 최저가 보기" "같은 제품 판매처 보기"
- 링크 주소는 프로젝트 지식의 제휴 링크 파일에서만 가져온다. 기억으로 만들지 않는다.

## 고지 문구 (글 맨 위, 그대로)
이 글은 제휴 링크를 포함하고 있으며, 구매나 예약 시 일정 수수료를 받을 수 있습니다.
협찬 제품이면 한 줄 더: 이 글은 업체로부터 제품을 제공받아 작성했습니다. 대가를 받았습니다.

## 금지
- 효능·치료·다이어트·탈모·질병 개선 같은 단정 표현
- "무조건", "100%", "국내 최저가" 같은 검증 불가 표현
- 별점을 근거 없이 매기기
- 다른 제품을 근거 없이 깎아내리기
- 발행 버튼 누르기 (임시저장까지만)

## 임시저장 전 점검
- 장단점 표에 아쉬운 점이 최소 2개 있는가
- 가격에 확인 날짜가 붙었는가
- 제휴 링크가 3개 이하이고, 고지가 맨 위에 있는가
- 제휴 링크가 실제로 열리는지 눌러서 확인했는가
- 사진에 얼굴·번호판·송장·주소가 없는가
