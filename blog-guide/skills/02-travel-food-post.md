# 여행·맛집 글쓰기

## 기본값
- 분량: 1,800~2,500자 (사진 6~12장 기준)
- 문단: 2~3문장. 한 문단이 4문장을 넘으면 나눈다.
- 말투: 존댓말, 담백하게. 감탄사 남발 금지.
- 마크다운 기호 금지: 네이버 에디터에는 `#`, `**`, `-`가 글자로 보인다. 소제목은 기호 없이 문장으로 쓴다.

## 구성 (이 순서를 지킨다)
1. 제목: 핵심 대상 + 조건 + 한 가지 이유 (30자 안팎)
   예) 애월 카페 3곳, 비 오는 날에도 창밖이 예뻤던 곳
2. 첫 3줄: 누가 읽으면 좋은지, 무엇을 알 수 있는지. 인사말로 시작하지 않는다.
3. 결론 먼저: 두 문장. "여기는 [상황]이면 갈 만합니다. 이유는 [핵심 2가지]입니다."
4. 정보 표: 장소명 / 주소 / 영업시간 / 가격대 / 주차 / 예약. 확인한 것만 채우고, 모르면 "확인 필요"로 둔다.
5. 본문 소제목 4~6개. 한 소제목에 사진 1~3장.
   - 어떤 상황이었는지
   - 실제로 시킨 것·본 것
   - 좋았던 점
   - 아쉬웠던 점 (최소 1개, 구체적으로)
   - 다시 간다면 이렇게
6. 마무리: 한 줄 정리 + 어떤 사람에게 맞는지.
7. 태그: 10개 내외. 핵심 키워드 3 + 지역 2 + 상황 3 + 브랜드 2.

## 사진 자리 표기
본문에는 사진을 넣을 자리를 아래처럼 표시하고, 실제 파일은 폴더에서 골라 그 자리에 넣는다.
[사진 1: 가게 외관, 간판 보이게]
[사진 2: 메뉴판]
[사진 3: 메인 메뉴 클로즈업]
사진 설명은 짧게. 같은 장소 사진이 3장을 넘으면 한 장으로 줄인다.

## 강조
- 굵게 표시 대신 문장을 짧게 끊어 강조한다.
- 가격·시간·거리는 문장 안에 숫자로 한 번만 쓴다.
- 비교가 필요하면 3줄 이내 표로 만든다.

## 고지
- 협찬·체험단이면 글 맨 위에 한 줄: "이 글은 업체로부터 제품 또는 서비스를 제공받아 작성했습니다."
- 제휴 링크가 있으면: "이 글은 제휴 링크를 포함하고 있으며, 구매나 예약 시 일정 수수료를 받을 수 있습니다."
- 내돈내산이면 굳이 쓰지 않아도 되지만, 협찬 글에 쓰면 안 된다.

## 사실 확인 규칙
- 영업시간·가격·주차는 확인한 날짜를 함께 적는다. 예) 2026년 11월 기준
- 확인하지 못한 값은 비워 두고, 사용자에게 "확인 필요"로 알린다.
- 줄 서는 시간, 대기, 예약 난이도는 내가 겪은 날짜와 시간대를 밝힌다.

## 임시저장 전 최종 점검
- 제목에 핵심 키워드가 들어갔는가
- 첫 문단에 결론이 있는가
- 아쉬운 점이 한 개 이상 있는가 (광고 글 느낌을 줄인다)
- 사진에 얼굴·번호판·주소가 그대로 있지 않은가
- 태그가 10개 안팎인가
- 발행은 하지 않는다. 저장까지만.
